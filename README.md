# AI Smart IQ Analyzer

A beginner-friendly five-question reasoning quiz built with Python and Streamlit.

## Features
- Name entry and welcome screen
- Five multiple-choice questions
- Logical, numerical, pattern and verbal reasoning
- Automatic scoring (one point per correct answer)
- Performance category and feedback
- Answer review with explanations
- Retake test option

## Requirements
- Python 3.10+
- Internet connection is not required to run this basic version

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens in your browser at the local address printed by Streamlit.

## Technology
- Python
- Streamlit

## Important limitation
This is an educational mini-quiz, not a standardized psychometric assessment. Five questions cannot reliably measure actual IQ. Results represent performance on these five questions only and must not be interpreted as a clinical or scientifically valid IQ score.
